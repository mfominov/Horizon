# Security Radar profile

Use this profile for current vulnerabilities and CVEs, exploitation reports, vendor advisories, security research, AppSec and DevSecOps findings, cloud-native and software-supply-chain security, and defensive security tooling.

Prioritize items relevant to Linux, Kubernetes, containers, CI/CD, web and API services, Java and OpenJDK, PostgreSQL, nginx, GitHub, and the software supply chain. The source is explicitly routed here for an independent Security Radar score. General security news without technical evidence or a concrete defensive implication should score low.
